# Executive Cheat Sheet: GIAIC 2026 & Anthropic FDE Certification Roadmap

Offical Book Link **[Certifications: Proof You Can Carry In](https://agentfactory.panaversity.org/docs/certifications)**

## 1. Strategic Transition: From Internal Training to Global Verification

GIAIC Final Exam shifted from internal assessments to third-party verified credentials recognized globally. This transition moves candidates from "personal claims" to "partner-verified" status with objective proof required by Claude Partner Network employers.

**Core Objectives:**

- **Global Credibility**: Anthropic’s official certification ecosystem
- **Architectural Competency**: Production-grade system architecture standards
- **Market Portability**: Standardized credential transcending individual training programs

This two-tier certification structure validates foundational competency before permitting production-grade agentic system deployment.

## 2. The Two-Tier Certification Pathway

Certification follows a progressive sequence: master AI judgment and evaluation (Tier 1) before designing autonomous agentic systems (Tier 2).

| Tier | Exam Code | Primary Focus / Competencies | Cost / Access |
| --- | --- | --- | --- |
| Tier 1: Pre-Qualification | PCAO-F | AI judgment, output evaluation, hallucination detection, responsible AI usage | Free (2 attempts for students) |
| Tier 1: Pre-Qualification | PCAR-F | System design, agentic architecture, Claude Code, MCP, context management | Free (2 attempts for students) |
| Tier 2: Global Credential | CCAO-F | Output validation (21%), workflow integration (16%), governance (15%) | $99 |
| Tier 2: Global Credential | CCAR-F | Agentic architecture (27%), Claude Code (20%), prompt engineering (20%), MCP/tools (18%) | $125 |

**Progression Logic:** Master evaluation (PCAO-F) → architecture (PCAR-F) → prove lifecycle management capability. Passing both Tier 1 exams unlocks FDE Internship Program and Tier 2 access.

## 3. Eligibility & Access Requirements

Tier 2 certification access is controlled via Panaversity’s Claude Partner Network membership.

- **Free Attempts**: Students receive 2 free attempts per Tier 1 exam; 3rd+ attempts require fees
- **FDE Internship Trigger**: Passing both PCAO-F and PCAR-F unlocks the FDE Internship Program
- **Partner Email Requirement**: Anthropic Tier 2 exams require organizational email (provided via internship); personal emails rejected

Only candidates passing Tier 1 exams receive partner-verified credentials to access official Anthropic certification.

## 4. Exam Specifications & Financial Investment

**Exam Format**

- **Proctoring**: Pearson VUE with identity verification
- **Duration**: 120 minutes
- **Questions**: 60 per exam (CCAO-F and CCAR-F)
- **Scoring**: 100-1,000 point scale
- **Passing Score**: 720/1,000
- **Format**: Multiple choice
- **Validity**: 12 months (renewable free if on-time; full retake if lapsed)

**Retake Policy**

- Up to 4 attempts per exam within 12 months
- Wait periods after failures: 14 days (1st), 30 days (2nd), 90 days (3rd)
- Each attempt costs full price

**Financial Investment**

- **Tier 2 Total**: $224 ($99 CCAO-F + $125 CCAR-F)
- **Value**: Official FDE competency proof from Claude creators
