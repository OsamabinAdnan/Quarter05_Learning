# Prompt for ChatGPT

I am creating a professional Agent Factory AI workflow.

My coding agent is Claude Code.

Your task is NOT to create the skills directly.

Instead, create a production-ready Claude Code prompt that will instruct Claude to:

1. Create a folder called skills

2. Inside the skills folder create:
    - linkedin_post_skill.md
    - design_optimization_skill.md
    - master_prompt_skill.md

3. Make every skill reusable

4. Follow best practices for Claude Code Skills

5. Use markdown format

6. Include:

- purpose
- instructions
- inputs
- outputs
- examples
- constraints

7. Ensure the LinkedIn Skill covers:

- tone
- hooks
- storytelling
- CTA
- hashtags

8. Ensure the Design Skill covers:

- brand guidelines
- typography
- colors
- layouts
- Canva optimization

9. Create a third reusable Master Prompt Skill that combines both skills.

10. After creating all skills, test them using a sample topic and verify they work correctly.

Return ONLY the final Claude Code prompt.
