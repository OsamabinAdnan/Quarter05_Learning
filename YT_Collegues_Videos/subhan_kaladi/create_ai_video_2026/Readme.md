## 2. The Fundamentals of Character Consistency

Character consistency is the most critical factor for success in social media algorithms. If a character's face, clothing, or color changes between scenes—such as an eggplant looking different in a village than in an office—the algorithm can flag the content as a low-quality glitch. This can prevent the video from entering viral loops.

### The Reference Method

Generate a primary base character first. This image becomes the permanent visual anchor for every later scene, helping the character remain recognizable to both viewers and the algorithm.

> **Character Consistency:** The technical process of ensuring a character keeps identical visual attributes, clothing, and textures across different scenes. It prevents algorithmic low-quality flags and helps retain viewers for viral growth.

## 6. Video Generation and Dialogue Synchronization

Convert static scenes into motion with the **Image to Video** feature in Google Flow.

### Technical Specifications

| Setting | Recommendation |
|---------|----------------|
| **Duration** | Use 8–10 second clips; the duration must match the dialogue length for synchronization |
| **Speed** | Maintain `1x` speed for realistic, natural movement |
| **Voice Model** | Use **Omni Flash** for realistic, human-like voices |

### The Dialogue Splitting Technique

Long dialogues can cause AI hallucinations, where the generator produces distorted visuals because of information overload.

If a scene's dialogue exceeds 10 seconds:

1. Split the dialogue text.
2. Generate two separate video clips.
3. Merge the segments in CapCut during final editing.

This preserves visual quality and dialogue synchronization.
