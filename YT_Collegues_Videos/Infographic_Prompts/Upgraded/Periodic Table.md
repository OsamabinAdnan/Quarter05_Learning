Create a highly detailed infographic titled **“The Periodic Table of Cocktails”**.

Design it as a **vintage scientific wall chart** inspired by early 1900s chemistry diagrams — refined, elegant, and slightly aged, like a collector’s print you’d find in an old European bar or study.

**Style & Aesthetic:**

- Old-school, high-taste design (not kitschy)
- Background: warm parchment / aged paper texture
- Color palette: muted creams, sepia, faded greens, dusty reds, soft gold accents
- Fine engraved linework and subtle ink imperfections
- Serif typography with a scholarly feel (small caps for headings, classic print layout)
- Ornamental flourishes in corners and title dividers

**Layout:**

- Structured exactly like a periodic table
- Each “element” represents a cocktail
- Clean, symmetrical grid with thin borders

**Each tile should include:**

- Cocktail name (primary, prominent)
- Abbreviation or 1–2 letter symbol (like chemical elements)
- Base spirit (e.g., gin, rum, tequila)
- Optional micro-icon (glass, citrus, garnish, etc.)

**Categories (like periodic groups), visually separated by subtle color differences:**

- Spirit Forward (e.g., Martini, Manhattan, Negroni)
- Sours (e.g., Whiskey Sour, Daiquiri)
- Refreshing / Highballs (e.g., Mojito, Gin & Tonic)
- Tropical (e.g., Piña Colada, Mai Tai)
- Dessert / After Dinner (e.g., Espresso Martini, White Russian)
- Sparkling (e.g., Mimosa, French 75)
- Hot / Warm (e.g., Hot Toddy, Irish Coffee)

**Additional details:**

- Include a small **legend/key** explaining categories
- Add a “How to Read” box (like real periodic tables)
- Include a footer with small illustrated icons of core ingredients (spirit, citrus, sugar, bitters, etc.)
- Optional elegant quote about cocktails or craftsmanship

**Lighting & Rendering:**

- Soft, even lighting like a scanned print
- High resolution, crisp but with analog warmth
- No modern UI or neon elements — timeless and sophisticated

**Overall Goal:**

Make it feel like a **museum-quality poster** — something a designer, bartender, or enthusiast would frame and hang.
