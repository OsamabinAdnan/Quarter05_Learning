# MASTER PROMPT — PREMIUM EDUCATIONAL INFOGRAPHIC

Create a **professional, information-dense educational infographic** in the style of a modern corporate learning framework, consulting presentation, AI education visual, or premium LinkedIn educational infographic.

The content/topic will be provided separately. Treat the supplied topic and content as the **source of truth**. Transform that content into a visually structured infographic without changing its meaning.

---

## 1. OVERALL DESIGN STYLE

Create a:

- Premium educational infographic
- Modern corporate/consulting visual
- Clean editorial information design
- Flat vector illustration style
- Structured learning-framework aesthetic
- Professional AI/technology education aesthetic
- Highly organized visual hierarchy
- Friendly but sophisticated visual language
- Information-rich but easy to scan

The final result should look like a professionally designed:

- Executive learning framework
- Corporate training infographic
- AI course visual
- Consulting framework
- LinkedIn educational infographic
- Workshop handout
- Knowledge map

Do NOT make it look like:

- A generic social-media poster
- A marketing advertisement
- A children's infographic
- A futuristic sci-fi poster
- A cluttered presentation slide
- A collection of unrelated boxes

The entire image must feel like **one coherent information system**.

---

# 2. CONTENT-FIRST APPROACH

Use the supplied content as the authoritative source.

First identify:

1. The central idea
2. Major concepts
3. Supporting concepts
4. Comparisons
5. Processes
6. Cause-and-effect relationships
7. Examples
8. Warnings
9. Outcomes
10. Final takeaway

Then convert those relationships into visual structures.

Do not simply place paragraphs into boxes.

Instead, use:

- Cards
- Diagrams
- Flows
- Comparisons
- Timelines
- Checklists
- Decision structures
- Before/after layouts
- Cause → effect relationships
- Numbered frameworks
- Process pipelines
- Visual hierarchies

Choose the appropriate structure based on the content.

---

# 3. INFORMATION ARCHITECTURE

Organize the infographic into approximately **5–8 major visual sections**, depending on the amount of content.

Each major section should have:

- A clearly visible section number
- A short descriptive title
- A colored header
- A lightly tinted content area
- Internal visual hierarchy
- Supporting icons/illustrations
- Consistent spacing

Use section numbers such as:

**1.**
**2.**
**3.**
etc.

Section titles should be short, strong, and easy to scan.

Do not force exactly the same number of sections if the supplied content requires fewer or more.

---

# 4. GRID & LAYOUT

Use a highly structured editorial grid.

Prefer a composition containing:

- Multiple rounded rectangular information panels
- 2–3 columns where appropriate
- Wider panels for important concepts
- Horizontal process sections
- Side-by-side comparison sections
- Full-width sections when a concept requires more space

Possible structure:

### Top
Central idea / key concept

### Upper-middle
Supporting concepts, comparison, or framework

### Middle
Examples, workflow, or cause/effect

### Lower-middle
Process / methodology / stages

### Bottom
Application, conclusion, or takeaway

The layout should adapt intelligently to the content.

Maintain:

- Equal outer margins
- Consistent gutters
- Strong alignment
- Consistent card dimensions where possible
- Balanced visual weight
- Clear reading order

---

# 5. SECTION HEADERS

Every major section should have a distinctive colored header strip.

Header characteristics:

- Rounded top corners
- Bold white section number
- Bold white section title
- Strong but professional color
- Consistent height
- Consistent typography

Use different semantic colors for different sections while keeping the overall palette harmonious.

Example palette:

- Blue
- Teal
- Green
- Purple
- Coral/red
- Orange
- Indigo

Avoid using every possible color randomly.

Colors should communicate categories or meaning.

---

# 6. COLOR SYSTEM

Use a **soft professional pastel palette with stronger colored headers and accents**.

Overall background:

- White
- Very light gray
- Very pale blue/gray

Primary text:

- Deep navy
- Dark charcoal

Accent colors:

- Medium blue
- Teal
- Green
- Purple
- Orange
- Coral/red
- Indigo

Semantic meaning:

### Blue
Information, technology, AI, general concepts

### Green
Success, good practice, approval, positive outcome

### Red
Failure, warning, risk, mistake, negative outcome

### Purple
Analysis, framework, evaluation, strategy

### Orange
Action, diagnosis, attention, transition

### Teal
Process, workflow, persistence, systems

Use **light tinted backgrounds** inside cards and stronger versions of the same color for headings/icons.

Do not oversaturate the entire image.

---

# 7. TYPOGRAPHY

Use a modern professional sans-serif font similar to:

- Inter
- Manrope
- SF Pro
- Helvetica Neue

Create a strong typography hierarchy:

### Level 1 — Main concept
Large, bold, highly prominent.

### Level 2 — Section titles
Bold and compact.

### Level 3 — Subheadings
Medium/bold.

### Level 4 — Supporting text
Regular weight.

### Level 5 — Labels
Small but highly legible.

Use bold selectively to emphasize important words.

Never allow body text to become tiny or difficult to read.

---

# 8. CENTRAL IDEA

If the supplied content contains a main thesis, principle, statement, or quote:

Make it the strongest visual element near the beginning of the infographic.

Use:

- Large bold typography
- Short statement
- Supporting explanation
- Simple conceptual illustration

Possible visual treatment:

**Main statement**

↓  

**Short explanation**

↓  

**Visual representation of the concept**

Use quotation marks when the source content contains a quote.

Do not bury the main idea inside a small card.

---

# 9. INFORMATION CARDS

Use rounded cards extensively.

Card characteristics:

- Rounded corners
- Thin subtle border
- Very light tinted background
- Small shadow or subtle depth
- Consistent internal padding
- Clear heading
- Supporting text
- Icon or illustration where useful

Cards should have enough breathing room.

Do not fill every available pixel.

---

# 10. VISUAL RELATIONSHIPS

Whenever the content describes a relationship, show it visually.

Use:

- → directional arrows
- ↔ comparisons
- ↓ sequences
- Connecting lines
- Dividers
- Numbered steps
- Flow diagrams
- Branches
- Checkmarks
- X marks
- Warning symbols
- Highlighted callouts

Examples:

**Input → Process → Output**

**Problem → Cause → Consequence**

**Step 1 → Step 2 → Step 3**

**Option A ↔ Option B**

**Good practice → Positive outcome**

**Mistake → Risk → Impact**

Arrows should have a clear semantic purpose.

---

# 11. COMPARISON SECTIONS

When the content compares two approaches, create a strong side-by-side structure.

Use:

### LEFT
Approach / Example A

### CENTER
Comparison indicator:

**VS**
or
**↔**
or
**SAME PRINCIPLE**

### RIGHT
Approach / Example B

Use different semantic backgrounds when appropriate.

For example:

- Green for the stronger approach
- Red/pink for the problematic approach

Make the comparison immediately understandable without requiring the reader to study the paragraphs.

---

# 12. PROCESS / FRAMEWORK SECTIONS

When the content contains a process, methodology, stages, or sequence:

Create a horizontal or vertical process diagram.

Each stage should contain:

- Number
- Icon
- Short title
- One concise explanation

Connect stages with arrows.

Example:

**1 → 2 → 3 → 4 → 5 → 6**

Use different but harmonious colors for individual stages.

The process should be visually recognizable as a sequence before the reader reads the supporting text.

---

# 13. CHECKLIST / EVALUATION SECTIONS

When the content contains criteria, questions, or evaluation factors:

Use a numbered checklist.

Structure each item as:

**① Icon + Short title**

Supporting explanation beneath it.

Keep the numbering visually dominant.

Use consistent icons.

Make the section feel like a practical diagnostic framework rather than a paragraph list.

---

# 14. CAUSE → EFFECT VISUALIZATION

For cause-and-effect information, create a visual chain.

Example:

**Action**

↓

**Problem**

↓

**Risk**

↓

**Real-world consequence**

Use progressively stronger visual emphasis as the consequences become more serious.

For positive flows:

**Action → Review → Approval → Success**

Use green checkmarks and positive visual cues.

For negative flows:

**Action → Error → Risk → Harm**

Use warning icons and red accents.

---

# 15. ICONOGRAPHY

Use clean modern vector icons.

Icons may include:

- AI robots
- People
- Teams
- Gears
- Documents
- Checkmarks
- X marks
- Warning triangles
- Calendars
- Databases
- Coins
- Magnifying glasses
- Maps
- Light bulbs
- Code symbols
- Targets
- Arrows
- Tools
- Screens
- Workflow symbols

Use a **single consistent icon style** throughout the infographic.

Icons should be:

- Simple
- Rounded
- Professional
- Recognizable
- Consistent in stroke/visual weight

Do not mix radically different icon styles.

---

# 16. HUMAN & AI ILLUSTRATIONS

When people are required, use friendly professional vector illustrations.

Human characteristics:

- Modern business/corporate appearance
- Simple facial features
- Natural poses
- Professional clothing
- Minimal visual detail
- Clean vector style

When AI is represented:

- Use a friendly modern robot
- Rounded geometry
- Simple face
- Technology-oriented appearance
- Blue/teal accents

Illustrations should support the information rather than dominate it.

---

# 17. POSITIVE VS NEGATIVE VISUAL LANGUAGE

For positive concepts use:

- Green accents
- Checkmarks
- Calm illustrations
- Soft green backgrounds
- Positive facial expressions
- Upward/rightward movement

For negative concepts use:

- Red/coral accents
- X marks
- Warning triangles
- Soft red backgrounds
- Concerned expressions
- Downward/failure movement

Maintain a professional tone.

Do not make negative sections visually aggressive.

---

# 18. CALLOUTS & TAKEAWAYS

Important insights should be placed inside visually distinct callout cards.

Use:

- Sticky-note style cards
- Highlight strips
- Bottom takeaway bars
- Target/insight cards
- Colored badges

Callouts should contain short, memorable statements.

Do not place long paragraphs inside callouts.

---

# 19. VISUAL EMPHASIS

Create a clear visual hierarchy.

The viewer should notice:

### First
The main idea

### Second
The major framework/concepts

### Third
The examples and comparisons

### Fourth
The detailed supporting information

### Fifth
The final takeaway

Use size, position, contrast, color, and whitespace to establish hierarchy.

Do not make every element equally prominent.

---

# 20. WHITESPACE

Use intentional whitespace.

Maintain:

- Comfortable margins
- Internal card padding
- Separation between sections
- Space around major illustrations
- Space between headings and body text

Avoid both:

- Excessive empty space
- Overcrowded layouts

The infographic should feel **dense with information but not cramped**.

---

# 21. VISUAL CONSISTENCY

Everything should belong to the same design system:

- Same corner radius
- Same typography family
- Same icon style
- Same illustration style
- Same arrow style
- Same border treatment
- Same shadow treatment
- Same spacing logic
- Same visual language

No individual section should look like it came from another infographic.

---

# 22. CONTENT PRESERVATION

Preserve the supplied content accurately.

Do not:

- Change technical terminology
- Replace important words with synonyms
- Alter relationships
- Remove important examples
- Invent facts
- Add unsupported claims
- Change the intended meaning

You may shorten long sentences **only when necessary for visual readability**, while preserving their original meaning and terminology.

If exact wording is provided, prioritize accurate rendering.

---

# 23. ADAPTIVE DESIGN

Do NOT blindly copy one fixed layout.

Instead, use the same **design language and visual system** while adapting the layout to the supplied topic.

For example:

### If the content is a process:
Use a process-heavy infographic.

### If it is a comparison:
Use side-by-side comparison panels.

### If it is a framework:
Use numbered modules/cards.

### If it is a timeline:
Use a chronological flow.

### If it is a checklist:
Use numbered diagnostic cards.

### If it is cause/effect:
Use connected causal chains.

### If it is educational:
Use concept → explanation → example → takeaway.

The **style remains consistent; the information architecture adapts to the content.**

---

# 24. PROFESSIONAL DETAIL LEVEL

Include subtle details that make the infographic feel professionally designed:

- Small section numbers
- Consistent icon placement
- Thin dividers
- Small semantic badges
- Subtle shadows
- Light card borders
- Rounded corners
- Carefully aligned arrows
- Consistent bullet spacing
- Small visual indicators
- Highlighted keywords
- Balanced text blocks
- Consistent line lengths
- Structured visual grouping

These details should improve usability, not become decoration.

---

# 25. FINAL TAKEAWAY

If the content contains an overall conclusion or key lesson:

Place it toward the bottom of the infographic in a strong concluding panel.

Use:

- Large icon
- Short bold statement
- One concise supporting sentence

Make it feel like the natural conclusion of everything above.

---

# 26. OUTPUT QUALITY

Generate an infographic that is:

- High resolution
- Extremely sharp
- Clean
- Professionally typeset
- Legible
- Well aligned
- Visually balanced
- Information-dense
- Easy to scan
- Suitable for professional publication

The result should resemble a **premium human-designed educational infographic**, not an automatically generated collection of text boxes.

---

# 27. CRITICAL GENERATION RULE

**Do not prioritize decoration over information.**

The hierarchy must always be:

**Meaning → Structure → Readability → Visual hierarchy → Illustration → Decoration**

The infographic must communicate the supplied knowledge clearly even when viewed quickly.

Create a polished, coherent, premium educational infographic using the supplied content as the source of truth.
