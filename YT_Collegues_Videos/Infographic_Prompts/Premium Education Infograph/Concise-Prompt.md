# MASTER PROMPT — EDUCATIONAL INFOGRAPHIC

Create a **premium, professional educational infographic** from the supplied topic/content. Use the content as the source of truth and preserve its meaning, terminology, relationships, examples, and key facts.

## VISUAL STYLE

Use a **modern corporate/consulting infographic style** with:

- Clean flat vector illustrations
- Rounded rectangular cards
- Strong colored section headers
- Soft pastel card backgrounds
- Dark navy/charcoal typography
- Simple consistent vector icons
- Subtle borders and shadows
- Clean arrows, dividers, checkmarks and warning symbols
- Professional AI, technology and business aesthetic
- Dense information but generous whitespace
- No photorealism, 3D renders, excessive gradients, neon colors, or visual clutter

The result should look like a **professionally designed AI course / corporate training / LinkedIn educational infographic**, not a generic poster.

## LAYOUT

Build the infographic using a structured editorial grid with **5–8 numbered sections**, adapting the layout to the content.

Use a combination of:

- 2–3 column panels
- Full-width sections
- Side-by-side comparisons
- Process flows
- Numbered frameworks
- Checklists
- Cause → effect diagrams
- Timeline/sequence layouts
- Final takeaway panels

Each major section should have:

**Number + short bold title + colored header + lightly tinted content area.**

Maintain consistent margins, spacing, alignment, card radius, icon style, and visual hierarchy.

## COLOR SYSTEM

Use a restrained professional palette:

- Blue — AI / information
- Green — success / good practice
- Red/coral — failure / warning / risk
- Purple — analysis / evaluation
- Orange — action / diagnosis
- Teal — process / workflow
- Indigo — strategy / conclusion

Use strong colors for headers and accents, with lighter versions for card backgrounds. Keep the overall image soft and professional, not oversaturated.

## TYPOGRAPHY

Use a highly legible modern sans-serif similar to **Inter, Manrope, SF Pro, or Helvetica Neue**.

Hierarchy:

**Main idea → Section title → Subheading → Supporting text → Labels**

Make important keywords bold and keep all text readable at infographic scale.

## INFORMATION DESIGN

Transform the supplied content into visuals rather than simply placing paragraphs into boxes.

Use the appropriate structure:

- **Concept:** main statement + explanation + illustration
- **Comparison:** A ↔ B with clear differences
- **Process:** numbered stages connected by arrows
- **Checklist:** numbered criteria with icons
- **Cause/effect:** action → problem → consequence
- **Workflow:** step → decision → outcome
- **Framework:** numbered modules/cards

Use arrows only when they represent a real relationship or sequence.

## ICONS & ILLUSTRATIONS

Use consistent modern vector icons such as:

AI robots, people, teams, gears, documents, checkmarks, X marks, warning triangles, calendars, databases, maps, light bulbs, code symbols, magnifying glasses, targets and workflow icons.

When people are needed, use **simple professional business-style vector characters**. When AI is needed, use a **friendly modern robot illustration**.

Illustrations should support comprehension, not dominate the content.

## VISUAL HIERARCHY

Make the viewer notice:

1. **Central idea / headline**
2. **Major concepts**
3. **Frameworks, comparisons or processes**
4. **Supporting examples**
5. **Final takeaway**

Use size, position, contrast, color, and whitespace to create this hierarchy.

## CONTENT RULES

- Do not invent facts.
- Do not change technical terminology.
- Do not remove important information.
- Do not distort relationships or meaning.
- Preserve important examples and numbers.
- Shorten wording only when necessary for readability.
- Make the central insight visually dominant.
- Adapt the layout to the topic instead of blindly copying a fixed template.

## FINAL QUALITY

Produce a **high-resolution, sharp, polished, highly readable infographic** that feels human-designed, coherent, information-rich, and suitable for professional publication.

**Priority:**
**Meaning → Information structure → Readability → Visual hierarchy → Illustrations → Decoration**
